セッションをまたぐ**揮発的な引継ぎメモ**。**このファイルは毎回上書き**（最新1件だけを保持する）。
過去の失敗の蓄積は `docs/failures.md`（append-only・消さない）を見る。

## ①今回実施

- **収支ラベルをin/out・fixed in/fixed outに変更**（PR#22）。あわせて画面全体の余白を詰め、
  予測残高の見出しを「Balance on [日付]」表記に変更。
- **UIをサブエージェントに抜本的に再設計させた**（PR#23、指示は「サブにリデザインさせろ」）。
  - 予測日・予測残高・グラフを1枚のカードに統合し、予測残高を視覚的な主役にする階層を確立。
  - 収支の記録一覧・毎日の固定費・毎月の固定収支をタブ切り替え（out/in/fixed）にまとめ、
    全機能は維持しつつ画面をすっきりさせた。
  - 金額表示をout=赤／in=青の配色に統一し、グラフの配色と一致させた。
  - **文言は当初サブに「小学生でも分かる表現で」と指示していたが、作業途中でユーザーから
    「小学生でもわかる表記は無し。大人用にしろ」と明確に上書き指示があり、途中からサブに
    修正させた**。最終的に画面文言は全て大人向けの表記（「予測日」「予測残高」「毎日の固定費」等）。
    ※この経緯を踏まえ、今後この種のトーン指示を出す際は「対象年齢」を最初に確認したほうがよい。
  - サブの成果物をレビューで検証したところ、`content.ts` 内に文言の重複（"を変更"が
    `HOME_TEXT`と`DETAIL_TEXT`の両方に同じ値で存在）と、`TransactionList`の未使用になった
    `heading` propが残っていた。AGENTS.md「結合を増やさない」に反するためこちらで統合・削除してから
    コミットした。サブの出力は鵜呑みにせず必ず重複・デッドコードをチェックすること。
  - 白ベース・イラスト無しの方針、1画面構成、in/out表記、「Balance on [日付]」は維持。
- 両PRとも `pnpm --filter web typecheck/lint/test/build` と `pnpm audit --audit-level moderate`
  を通し、Playwrightで実画面を目視確認してからマージ済み（squash、`main`へ反映済み）。

証拠：PR#22・PR#23（いずれもマージ済み、`ci-green`緑を確認）。

## ②今回トラブル

- squashマージ後、同じ作業ブランチに新規コミットを積んでpushすると毎回
  merge-baseがズレて `git diff`/PRの差分が想定外に膨れる現象が今回も2回発生した
  （`docs/failures.md`に記録済みの既知の癖）。都度 `git merge origin/main --no-edit` で
  解消したが、今回はセッション終了時に**未反映の作業が無い状態だったため、
  `git checkout -B claude/in-3do8qg origin/main` でブランチを最新mainから作り直した**。
  次回セッション開始時、このブランチは`main`と完全に同じ状態から始まる。
