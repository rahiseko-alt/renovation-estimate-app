# 操作説明書

このアプリは、**現場で撮った写真から、複数の下請会社へまとめて見積を頼み、返ってきた金額を並べて比べる**ためのものです。
スマートフォンで使えます。アプリのインストールは要りません。ブラウザで開いてください。

---

## まず触ってみる（3回押すだけ）

**設定も登録もログインも要りません。** どんなものか見るだけなら、ここだけで済みます。

1. トップ画面の「**デモを触ってみる**」を押す
2. 「**写真を撮る**」（いま居る部屋で構いません）か「**写真なしで進む**」を押す
3. 3社から返ってきた見積が並んだ画面が出るので、「**見積書PDFを出力**」を押す

これで見積書が1枚できます。**表示されるデータはすべて架空のものです。**

裏では、会社設定・下請台帳・法定項目21件・3社への依頼と回答がすべて入った状態になっています。
比較の画面から「中身を見る」で確かめられます。

---

## この先は、実際に使いはじめる方向けです

ここから下は、**自社の情報を入れて本当の見積を作る**ときの手順です。
デモを見るだけなら読む必要はありません。

## 1. 使いはじめる前に、1回だけやること

最初に1回だけ設定します。**ここを飛ばすと、あとで毎回同じことを打つはめになります。**

### 1-1. ログインする

配布されたアドレスを開き、メールアドレスとパスワードを入れて「**ログインする**」を押します。

> アカウントはこちらで用意します。ご自身で登録する画面はありません。

ログインすると、行き先が3つ並んだ画面（トップ画面）が出ます。

| 行き先 | 何をするところか |
|---|---|
| **案件** | 現場ごとの作業。写真・工事の中身・依頼・比較まで、ぜんぶここから |
| **下請台帳** | 見積を頼む会社の連絡先を登録しておくところ |
| **会社設定** | 自社の名前と、毎回同じことを書く手間を省く設定 |

これから触るのは下の2つです。

### 1-2. 会社設定（自社のことを登録する）

トップ画面の「**会社設定**」を押します。

**上半分：請負者情報**

見積書に印字される自社の情報です。3つ入れてください。

- 請負者名（会社名）
- 代表者名
- 住所

**下半分：法定項目の定型文**

ここが、いちばん手間を減らせるところです。

リフォーム工事の見積依頼には、法律で「これを書いて渡しなさい」と決まっている項目があります。そのうち**7つは、どの現場でもだいたい同じ内容**を書くことになります。

| 欄 | 何を書くか（例） |
|---|---|
| 責任施工範囲 | どこまでを下請にやってもらうか |
| 見積条件 | 見積を出すうえでの前提 |
| 他工種との関係部位 | 他の業者と作業が重なるところ |
| 特殊部分 | 特別な作業が要るところ |
| 材料費の負担 | 材料はどちらが用意するか |
| 労働災害防止対策の負担 | 安全対策の費用はどちらが持つか |
| 建設副産物の運搬及び処理の負担 | 廃材の処分はどちらが持つか |

ここに1回書いておくと、**このあと作る現場すべてに、最初から同じ内容が入った状態で始まります。**

「**保存する**」を押して終わりです。

> **注意：**あとから会社設定を直しても、**すでに作った現場の内容は変わりません。**
> 「あの現場だけ書き方を変えたい」というときに、他の現場が巻き添えで書き換わらないようにするためです。
> 直した内容が入るのは、直したあとに作る現場からです。

### 1-3. 下請台帳（見積を頼む会社を登録する）

トップ画面の「**下請台帳**」を押します。

「会社を登録する」の欄に、**会社名**と**メールアドレス**を入れて「**登録する**」。頼みたい会社の数だけ繰り返します。

**見積の送り先は、ここに登録した会社からしか選べません。** 1社も登録していないと、あとで依頼を出せません。

登録した会社は一覧に並びます。使わなくなったら「削除」で消せます。

## 2. 見積を1件つくる（ここが本編）

ここからは現場1件ぶんの流れです。**上から順にやれば終わります。**

### 2-1. 現場を登録する

トップ画面の「**案件**」→「**新しい案件**」を押します。

- **施主名**（お客様のお名前）
- **現場住所**

2つ入れて「**登録する**」。これで現場が1件できます。

このとき、会社設定に書いた定型文が、この現場に自動で入ります。**あとで確認するだけで済みます。**

### 2-2. 写真を撮る

登録した現場を開くと、下のほうに写真の欄があります。

撮る場所（キッチン・浴室・内装など）を選んでから、カメラのマークを押して撮ります。すでに撮ってある写真を選ぶこともできます。

写真は自動で軽くしてから送るので、電波が弱くても比較的通ります。

### 2-3. 工事の中身を書く

現場の画面で「**見積をつくる**」を押します。

「**明細を追加**」を押すと1行増えます。1行につき、次を入れます。

| 欄 | 入れるもの |
|---|---|
| 工事項目 | 何の工事か（例：クロス張替） |
| 摘要 | 補足の説明 |
| 数量 | いくつ・何㎡か |
| 単位 | ㎡・m・箇所・式 など |
| 単価 | 1つあたりの金額 |

**単価は空のままで構いません。** ここを下請会社に埋めてもらうのが、このアプリのいちばんの目的です。自分で相場を調べて埋める必要はありません。

いくつか補足します。

- **「式」を選ぶときは、摘要に中身を書いてください。**「式」だけでは何をいくつやるのか相手に伝わりません。画面にも注意が出ます。
- **諸経費率（%）**の欄があります。**空欄のままにせず、案件ごとに入れてください。**業界で決まった率というものが存在しないので、こちらで初期値を用意していません。
- 値引きを入れたいときは、種別を「値引き」にした行を足します。

最後に「**保存する**」。

> **らくをするコツ：**よく使う工事項目と単価は、案件一覧の「単価マスタ」に登録しておけます。
> 登録しておくと、明細を足すときに選ぶだけで入ります。

### 2-4. 法定項目・施工条件を確認する

現場の画面に戻って「**法定項目・施工条件を入力する**」を押します。

**ここを通らないと依頼を送れません。** 法律で決まっている項目なので、アプリ側で省略できないようになっています。

画面は上下2つに分かれています。

**上：法定項目（9つ）**

それぞれに3つの選択肢があります。

| 選ぶもの | 意味 |
|---|---|
| **記入する** | 内容が決まっている。下の欄に文章を書く |
| **未定** | まだ決まっていない。**「未定」と書類に印字されます** |
| **未入力** | 手を付けていない。**これが残っていると送れません** |

会社設定に定型文を入れてあれば、**7つは最初から「記入する」になっていて、文章も入っています。**そのままでよければ触らなくて構いません。

残る2つは**工程**（下請工事の工程・全体工程）です。ここは現場ごとに日付が違うので、毎回入れてください。決まっていなければ「未定」で構いません。

**下：施工条件・範囲リスト（12区分）**

材料／組立・加工／運搬／足場／墨出し／養生／片付け／機器／図面・書類／見本／検査・確認／安全 の12個に、印を付けます。

| 印 | 意味 |
|---|---|
| **○ 含める** | この依頼に含める |
| **× 含めない** | この依頼には含めない |
| **未検討** | 最初はこれ。**1つでも残っていると送れません** |

12個すべてに ○ か × を付けてください。

上下ぜんぶ入れ終わったら、いちばん下の「**保存する**」を1回押します。**21項目まとめて保存されます。**

### 2-5. 見積依頼を出す

現場の画面で「**見積依頼を出す**」を押します。

**まず、送れる状態かどうかの確認結果が出ます。**

- 全部そろっていれば「法定項目はすべて記入済みです。」
- 足りなければ、**足りない項目の名前が並びます。**その場所から法定項目の画面へ直しに行けます

そろっていたら、次の2つを選びます。

**送り先**
下請台帳に登録した会社が並びます。**頼みたい会社にチェックを入れます。何社でも同時に選べます。**

**予定価格帯**
工事のおおよその金額を3つから選びます。

| 選ぶもの | 相手に与えられる考える時間 |
|---|---|
| 500万円未満 | 1日以上 |
| 500万円以上 5,000万円未満 | 10日以上 |
| 5,000万円以上 | 15日以上 |

**この選択が、見積の回答期限を決めます。**法律で「金額に応じてこれだけの期間を与えなさい」と定められているので、勘で短くすることはできません。

「**この内容で送る**」を押すと、選んだ会社それぞれに依頼が届きます。

### 2-6. 返事を比べて決める

現場の画面で「**見積を比較する**」を押します。

工事の項目が縦に、依頼した会社が横に並んだ表が出ます。**同じ工事に対する各社の金額が、横一列で見比べられます。**

- まだ返事の来ていない会社は「回答待ち」
- いちばん安いところに「**最安**」の印が付きます

> **印は目安です。自動では選びません。**
> 安いところが常に正しいとは限らないので、決めるのはご自身です。

採用したい会社の「**採用する**」を押します。**工事の項目ごとに、別々の会社を選べます。**「A社は安いが、この部分だけはB社」という選び方ができます。

選び直したいときは、別の会社の「採用する」を押すか、「採用をやめる」を押します。

### 2-7. 見積書を出す

現場の画面で「**見積書PDFを出力**」を押します。

会社設定に入れた自社の情報が入った見積書が、PDFで出ます。そのまま印刷しても、メールに添付してもかまいません。

## 3. 下請会社側の画面

依頼を受けた会社に何が見えるのかを書いておきます。**説明を求められたときのために目を通しておいてください。**

- **ログインは要りません。**届いたリンクを開くだけです。相手にアカウントを作ってもらう必要はありません
- 見えるのは**工事名称・施工場所・回答期限・工事の中身**だけです
- **施主名と、こちらが考えている金額は相手に見えません**
- 相手は工事の項目ごとに**数量と単価**を入れます
- そのほかに、材料費・労務費・法定福利費・安全衛生経費・建設業退職金共済掛金・作業日数を書く欄があります。**これは法律上「書くよう努める」とされている項目なので、空欄でも送れます**
- **回答は1回だけです。**送信後は書き直せません

## 4. 困ったとき

### 「見積依頼を出す」を押しても送れない

画面に足りない項目の名前が出ています。よくあるのは次の2つです。

- **法定項目に「未入力」が残っている** → 「記入する」か「未定」を選んでください
- **施工条件に「未検討」が残っている** → 12個すべてに ○ か × を付けてください

その画面から直しに行けるようになっています。

### 送り先に会社が1社も出てこない

下請台帳に登録がありません。「下請台帳を開く」から会社を登録してください。

### 新しい現場に定型文が入っていない

会社設定が空のまま現場を作った可能性があります。会社設定に書いてから、**もう一度現場を作り直して**ください。**すでに作った現場には、あとから自動で入りません。**

### 会社設定を直したのに、現場の内容が変わらない

**そういう作りです。**すでに作った現場は、その現場だけの内容として切り離されています。直したい現場を開いて、直接書き換えてください。

### 保存したのに金額が合わない

諸経費率が空欄のままになっていないか確認してください。案件ごとに入れる欄です。

### 写真がなかなか上がらない

電波の弱い場所では時間がかかります。電波の届く場所で開き直してください。

### 相手が「リンクが開けない」と言っている

同じリンクは1回しか使えません。すでに回答済みの場合は「この依頼は既に回答済みです」と表示されます。回答をやり直してもらう必要があるときは、依頼を出し直してください。

## 5. 言葉の意味

**案件**
現場1件のこと。施主名と現場住所で区別します。

**明細**
工事の中身を1行ずつ書いたもの。「クロス張替 30㎡」で1行です。

**法定項目**
建設業法で「見積を頼むときに相手へ示しなさい」と決まっている項目。省略できません。

**未定**
「まだ決まっていない」ということが決まっている状態。**手つかずの「未入力」とは別物**で、書類には「未定」と印字されます。

**施工条件・範囲リスト**
どこまでを依頼に含めるかを12の区分で示すもの。あとで「それは頼まれていない」と揉めないためのものです。

**予定価格帯**
工事のおおよその金額。相手に与える回答期間が、これで決まります。

**諸経費**
現場管理や事務にかかる費用。工事そのものの金額に上乗せするぶんです。

**単価マスタ**
よく使う工事項目と単価を登録しておく場所。明細を書くときに選ぶだけで済みます。
